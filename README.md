# AstraDesk for Windows

Public installer downloads for [AstraDesk](https://www.astradesk.org/).

This repository is **not** the product source. It exists so the Windows installer can be downloaded in a browser. The main AstraDesk codebase stays private.

## Publisher

- Product: AstraDesk — invoices, contracts, and e-signatures
- Publisher: Niall Darby / Star-Tek IT Services, Ireland
- Company page: https://www.astradesk.org/company.html
- Mac App Store: https://apps.apple.com/app/astradesk/id6783929265 (seller: Niall Darby)
- Windows download page: https://www.astradesk.org/windows/

## Files

Download the latest [windows-desktop release](https://github.com/ND1-Sdo/AstraDesk-Windows/releases/tag/windows-desktop):

- `AstraDesk-Setup.exe` — installer (adds AstraDesk to the Start menu)
- `AstraDesk-Windows.zip` — portable build (unzip and run `AstraDesk.exe`)

This is **not** a Microsoft Store app. Windows SmartScreen may warn on a first download. Choose **More info**, then **Run anyway**.

After install, sign in with the same licensed account you use on the web or the App Store.
